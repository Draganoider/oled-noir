# Contributing to OLED Noir

Thanks for wanting to make OLED Noir better. Bug reports, ideas for looks and pull requests are all welcome.

## Reporting a problem

Open an issue with the bug report form. Say which look and settings you had on (`/noir list` shows them), your Claude desktop app and Claude Code versions, and what you saw. A screenshot helps a lot.

## Running it from a clone

1. Clone the repository.
2. Start Claude Code with the folder loaded: `claude --plugin-dir <path to the clone>`. Or add the clone as a marketplace and install from it, so the desktop app loads it in every session:

   ```
   claude plugin marketplace add <path to the clone>
   claude plugin install oled-noir@oled-noir
   ```

3. After each edit, run `/reload-plugins` in the session.

Before opening a pull request, run:

```
claude plugin validate .
claude plugin test .
```

Both should pass with no errors.

## Adding a look

A look is one entry in `VARIANTS` in `hooks/variants.ts`, and usually one scene function in `hooks/scenes.ts`.

A scene is an SVG string built in code: a `1600 × 1000` view box with `preserveAspectRatio="xMidYMid slice"`, animated with CSS in its own `<style>`. Keep to what makes OLED Noir what it is:

- **Black and white.** A `#000000` ground and white or gray light. No color.
- **Most pixels off.** Thin lines, small dots, sparse light.
- **Light at the edges.** Keep the subject in the margins and corners, away from the middle where the words sit and the foot where the prompt sits.
- **Slow motion only.** Nothing may flash: no spot should swing between light and dark more than about three times a second. Prefer changes that take several seconds.
- **A finished still.** With reduced motion, animations are removed; give every moving part a sensible resting place in the plain markup.
- **Pure vector.** No `<image>`, no embedded fonts, no external references, and every `id` must contain a hyphen. Keep each scene under 128 KB.

Then:

1. Add the look to `VARIANTS`, with a short `blurb`.
2. Add its scene to `scripts/build-previews.mjs` and run `node scripts/build-previews.mjs` (Node 23.6 or newer) to make its preview.
3. Add it to the gallery in `README.md` and to `CHANGELOG.md`.
4. Run the tests: they check that every scene is a valid, pure-vector SVG of the right size.

## Style

- TypeScript, two-space indents, single quotes, no semicolons, as in the existing files.
- Leave `hooks/make-colors.js` and `hooks/make-colors.d.ts` unchanged: they are generated by Claude Code's plugin kit.
- Keep messages the mod shows short and plain.
